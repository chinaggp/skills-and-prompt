# Windows Black Hole 参考图 UI 重设计

## 文档状态

- 日期：2026-07-24
- 状态：已完成对话设计确认，等待书面规范复核
- 目标目录：`plugins/windows-black-hole/`
- 参考图：用户提供的电影感黑洞图
- 设计方向：透明悬浮电影感黑洞

## 1. 背景

当前 Windows Black Hole MVP 使用 WPF 图元绘制完整黑洞，并通过原生
Direct3D 11/HLSL 模块捕获和扭曲黑洞后方的桌面背景。现有界面已经具备
透明、无边框、始终置顶、中心拖动和文件投放功能，但黑洞本体仍由规则椭圆
和少量路径组成，视觉层次、光照方向与参考图差距明显。

本次改造在不改变产品形态和删除语义的前提下，以参考图的黑色事件视界、
白金与橙色吸积盘、弯曲时空网格、左下伴星和底部仪表语言重新设计界面。

## 2. 目标

1. 保持 `520 × 520` 透明悬浮桌面小组件形态。
2. 将黑洞改造成接近参考图的电影感、非对称、高对比视觉。
3. 保持事件视界真实交互中心为 `(260, 260)`，不降低投放准确性。
4. 为静止、鼠标靠近、文件拖入、可投放、成功和失败状态提供一致动效。
5. 保留现有桌面捕获和引力透镜实现，不让 UI 改造覆盖原生渲染工作。
6. 保留 Windows Shell 回收站语义，成功动画只能在 Shell 操作成功后播放。

## 3. 非目标

- 不改成有实体背景的圆角宇宙卡片。
- 不增加标题栏、常驻按钮、设置面板或底部常驻信息栏。
- 不改变支持投放的文件类型、安全校验或回收站实现。
- 不重写原生捕获、D3D 交换链或引力透镜着色器。
- 不引入图片下载、网络资源、遥测或第三方 UI 组件。
- 左下伴星和物质流仅为视觉元素，不新增第二投放区域。

## 4. 视觉构图

窗口继续使用透明背景，所有可见元素在边缘渐隐。

### 4.1 主黑洞

- 事件视界的几何中心保持 `(260, 260)`。
- 黑色核心保持圆形和完全不透明，视觉直径约 `132` 逻辑像素。
- 核心外侧使用细金色光子环、白金高光和柔和琥珀色辉光。
- 通过光效和吸积盘的不对称分布使视觉重心略偏右，但不移动命中区。

### 4.2 吸积盘

- 主方向为左低右高的斜向流线。
- 中心高光使用白色和浅金色，向外过渡为琥珀色、橙色和透明尾焰。
- 使用多条不同粗细、透明度和模糊半径的路径组成，不再以规则椭圆作为
  最显眼的轮廓。
- 前景盘从事件视界前方穿过，后景盘向上弯折，形成参考图中的引力透镜层次。

### 4.3 环境元素

- 左下放置弱化伴星、局部熔岩辉光和连接主黑洞的物质流。
- 外围使用低透明度弯曲网格表现时空形变。
- 星尘和少量光点只用于补充空间深度，不形成噪点密集的实体背景。
- 窗口四边保持透明，避免出现矩形卡片边界。

### 4.4 状态仪表

- 状态提示沿用参考图的窄字距、仪表式排版。
- 提示只在拖放或结果反馈时淡入，空闲状态不常驻。
- 文案状态包括 `GRAVITY LOCK`、`RELEASE TO CONSUME`、成功数量和失败原因。
- 中文操作说明与英文仪表标签可以同时出现，但错误原因必须保持可读。

## 5. 交互与动效

### 5.1 空闲

- 吸积盘低速连续旋转。
- 流线亮度做轻微呼吸变化。
- 星尘缓慢漂移，避免静态贴图感。

### 5.2 鼠标靠近

- 光子环亮度和外发光随 `BlackHoleGeometry.Proximity` 增强。
- 吸积盘旋转速度、缩放和偏斜幅度平滑提升。
- 时空网格向中心收束。
- 原生桌面透镜接收相同接近度，保持视觉反馈同步。

### 5.3 文件拖入

- 文件进入影响范围后，物质流向事件视界拉伸，显示 `GRAVITY LOCK`。
- 文件进入事件视界后，光子环切换为白金高亮，显示
  `RELEASE TO CONSUME`。
- 事件视界之外释放时不执行删除，并显示明确的未吞噬反馈。

### 5.4 成功与失败

- Windows Shell 确认对象已移入回收站后，才播放约 `520 ms` 的核心收缩、
  白金闪光和向外冲击环。
- 失败或无效投放不播放成功动画。
- 失败时光子环短暂切换为红橙色，并显示经过裁剪的错误说明。

### 5.5 窗口移动

- 保持按住事件视界中心调用 `DragMove`。
- 不增加独立拖拽手柄。
- 状态和装饰图层不得截获事件视界的鼠标输入。

## 6. 实现边界

### 6.1 WPF

`MainWindow.xaml` 负责分层绘制：

1. 星尘；
2. 时空网格；
3. 左下伴星和物质流；
4. 后景吸积盘；
5. 光子环与事件视界；
6. 前景吸积盘；
7. 投放脉冲；
8. 状态仪表。

`MainWindow.xaml.cs` 负责：

- 统一更新接近度驱动的旋转、缩放、偏斜、透明度和光效；
- 在拖入、命中、成功和失败状态之间切换；
- 保持回收站调用先于成功动画；
- 复用现有 `DispatcherTimer`，不创建多个永久动画计时器。

### 6.2 Core

`BlackHoleGeometry` 继续使用：

- `WindowSize = 520`
- `Center = 260`
- `EventHorizonRadius = 66`
- `InfluenceRadius = 235`

视觉偏移不能改变这些交互常量。测试补充事件视界边界内外和影响半径边界
断言。

### 6.3 原生渲染

现有 `WindowsBlackHole.Renderer`、桌面捕获、DirectComposition 和
`GravitationalLens.hlsl` 保持原有职责。本次改造不覆盖其未提交变更，只验证
WPF 黑洞与原生背景透镜叠加时的位置、尺寸和 DPI 一致性。

## 7. 错误处理

- 没有文件数据：不允许投放，不播放错误动画。
- 文件不在事件视界内：显示未吞噬说明，不调用回收站服务。
- 路径校验失败：保留 `DropValidator` 返回的原因。
- Windows Shell 失败：显示异常信息并播放红橙色脉冲。
- 原生捕获不可用：WPF 黑洞仍完整可见，拖放与回收站功能继续工作。
